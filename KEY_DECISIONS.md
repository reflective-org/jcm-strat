# Key decisions

Every default in this repo and why it is what it is. Newer entries at the bottom.
If `docs/` disagrees with this file, this file is current.

| # | Date | Decision | Why |
|---|---|---|---|
| 1 | 2026-09-02 | Repo is a config overlay + tiny package, **not a fork of JCM** | JCM `dev` moves daily; we must be able to follow it with a SHA bump. Hydra `--config-dir` makes an overlay trivial. |
| 2 | 2026-09-02 | Upstreams pinned as submodules: jax-gcm `849893b` (dev, 2026-09-01), dinosaur `bd99e39b` (semi-lagrangian, 2026-08-24) | JCM's dinosaur requirement is a floating branch name; an unpinned install is not reproducible. |
| 3 | 2026-09-02 | Own environment under `/data/JCM_stripped/jcm-strat/`; nothing from other users' homes | Only SL-capable Dinosaur on the machine sat in a colleague's venv; `/data/jax-gcm-fork` is a stale June snapshot. Root disk 97% full → all caches inside the repo. |
| 4 | 2026-09-02 | **GPU 0 only**, runs strictly sequential | Shared 8×H100 node; user requirement. |
| 5 | 2026-09-02 | Phase-1 grid **T63L95** (existing, lid 0.01 hPa); ~30-level grid later | Only 40/47/95-level tables exist in JCM; a new table needs code + diffusion orders. Validate the physics first on a validated parent grid, then reduce and A/B. |
| 6 | 2026-09-02 | Stratospheric temperature held by **Held-Suarez relaxation** in Phase 1; RRTMGP filed as an issue | Zero code; radiation is the dominant cost and would blur the speed number. Known limitation: no polar-night jet in the HS profile (Polvani-Kushner is a deferred issue). |
| 7 | 2026-09-02 | ERA5 nudging of **winds + temperature**, τ = 6 h, `pbl_levels: 2` | With convection removed, only relaxation would hold up tropospheric T. |
| 8 | 2026-09-02 | Nudging cutoff **150 hPa hard mask for now** (`nudging.min_pressure_hpa: 150`) | Comparable to AIDE-SAI-link's 150 hPa domain; one YAML key. Must become a dynamical tropopause (issue). WeatherBench2 ERA5 has no usable data above ~60 hPa anyway. |
| 9 | 2026-09-02 | ERA5 period **2005–2009** | Quiet volcanically; overlaps CLaMS age-of-air reference (2004–2023); three observed SSWs (Jan 2006, Feb 2008, Jan 2009). |
| 10 | 2026-09-02 | Age-of-air clock tracer reset where **p > 700 hPa** | Standard clock-tracer convention; comparable to CLaMS and WACCM `AOA1` references on `/data`. |
| 11 | 2026-09-02 | No conservation code in Phase 1 | JCM's dycore already applies a global proportional mass fixer to SL tracers (`_fix_nodal_tracer_mass`, on by default). A `unity` tracer measures what it hides. |
| 12 | 2026-09-02 | Each phase ships `docs/outputs/<NN>/output.md` + tracked plots | Scientific model: every step is validated and the evidence is reviewable in the PR. |
| 13 | 2026-09-02 | `env.sh` exports `LD_LIBRARY_PATH` to the containerised driver mount (`/run/nvidia/driver/usr/lib/x86_64-linux-gnu`) | `libcuda.so.1` is off the loader path on this node; without it JAX silently ran on CPU. Same trap AIDE-SAI-link guards against in `run_prod.py`. |
| 14 | 2026-09-02 | Baseline timed with two 5-day chunks; steady-state number = chunk 1 | Chunk 0 includes JIT compile. The persistent compile cache lives in `scratch/jcm-jax-cache`. |
| 15 | 2026-09-02 | Repo public; `dev` is the default branch, phase branches fork from and merge into `dev`, `main` = release points | Requested by Susanne; mirrors jax-gcm's own `dev`/`main` convention. |
| 16 | 2026-09-02 | Phase 2–3 physics is `strat_dry` (Held-Suarez only); gravity-wave drag deferred to issue #20 | Held-Suarez is a full-field term, Hines/Lott-Miller are column-vectorized; composing them needs a column-vectorized Held-Suarez (new code), out of scope for Phase 1. |
| 17 | 2026-09-03 | Phase 3 physics runs column-vectorized with `HeldSuarezColumns`, a per-column subclass of JCM's `HeldSuarez` with identical forcing | JCM's 3-D physics path cannot accumulate tracer tendencies across terms (PhysicsTendency trees with different tracer dicts do not add), and the stock `HeldSuarez` takes latitude from the 1-D grid axis so it cannot sit on the column path. The subclass changes only the coordinate cache. Upstream candidate (issue #13); gravity-wave terms would compose on this path too (issue #20). |
| 18 | 2026-09-03 | The injection tracer `sai` is a continuous source (1e-6 s⁻¹, 15°S–15°N, 25–55 hPa) rather than the plan's initial pulse; the clock `aoa` is in days; the shape tracers are `unity` and `e90` | A continuous source gives a conservation test with an analytic answer (burden = source × box mass × t) instead of a "should not change" test; e90 doubles as the tropopause marker the plan wanted. Tracer tendencies are per second and converted to the dycore's nondimensional time exactly as HeldSuarez converts its rates; verified by the day-mean clock reading 0.50 d after one day. |
| 19 | 2026-09-03 | The age-of-air clock is excluded from the dycore's global mass fixer (`sl_mass_fixer_exclude: [aoa]`, honoured by `jcm_strat.main`); the fixer stays on for every conserved tracer | A clock is not a conserved quantity. With the fixer on, the limiter's spurious mass creation at the sharp 700 hPa reset edge was removed by rescaling the whole field, slowing the stratospheric clock from 1.00 to 0.44 day/day over one year (`p3_tracers_1yr_fixerbug`). `jcm_strat.main` wraps `jcm.main` because the runner's `sl_options` carries only `off_centering`; upstream candidate (issue #13). |
| 20 | 2026-09-03 | Multi-year nudged runs are chained one-calendar-year segments (`init=from_state` from the previous segment's checkpoint), not one long run | JCM keeps the whole ERA5 nudging target on the GPU; 5 years at L95 6-hourly is 154 GB vs 80 GB (run `p4_5yr_oom`), 1 year (31 GB) fits. The full state incl. tracers carries over exactly (checked at every boundary). Upstream fix: stream the target (issue #26). |
| 21 | 2026-09-03 | Phase-4 fidelity checks that fail (tropical age of air, no polar-night jet) are recorded as failures against the Held-Suarez stratosphere, not tuned away | The speed question Approach A was set up to answer is answered (≈5 GPU-h per 30 yr). The fidelity gap is the stratospheric forcing (issues #2, #5); the clock referencing question is issue #25. Tuning transport to match CLaMS with the wrong circulation would hide the cause. |
| 22 | 2026-09-03 | Two age-of-air clocks side by side from now on: surface reset (CLaMS/WACCM boundary condition) and reset below 150 hPa (entry age). Implemented first in the offline PARADIS clock; jcm-strat adds the second clock in its next multi-year run | Phase 4 showed the 700 hPa clock mixes tropospheric transit into the stratospheric age in a model without convective mixing (issue #25); the entry age scores stratospheric transport only and is comparable to WACCM, the surface clock to CLaMS. |
| 23 | 2026-09-03 | Stratospheric temperature is held by a seasonal Polvani-Kushner (2002) equilibrium (`jcm_strat/polvani_kushner.py`), not by a relaxation toward an ERA5/WACCM climatology and not by radiation | The analytic target keeps the comparison against ERA5 and WACCM an honest test; radiation is the dominant cost of the full model (Phase 0). The winter hemisphere follows the calendar through `forcing.solar.tyear`. |
| 24 | 2026-09-03 | Stratospheric relaxation time 15 d (PK02: 40 d), cooling season equinox-to-equinox (`season_offset` 0.5), vortex cooling faded out above 3 hPa | Eight 2005 A/B runs: tau is the dominant knob (RMSE 100-1 hPa vs ERA5 8.9 -> 6.7 K, jets from ~55 to ~90 percent of ERA5); the wide season fixes the autumn onset; PK02's unbounded cooling aloft (143 K at 3 hPa) has to be capped. 15 d is the radiative damping time the handover asks for once aerosol heating is on. |
| 25 | 2026-09-03 | The full-ECHAM reference year runs the nudging target at 12-hourly sampling and on GPU 1 | Full physics + the 6-hourly 31 GB target does not fit an 80 GB card (OOM at the first step); GPU 1 (and later GPU 2) were released to the project for this phase so GPU 0 stays on the 10-minute PK iterations. |
| 23 | 2026-09-04 | QBO nudging (Phase 8): relax only the zonal-mean tropical wind towards ERA5 monthly zonal means (CDS, 25 levels, the model years), \|lat\| ≤ 15° full weight tapering to 0 at 25°, 9–40 hPa full weight tapering to 0 at 4 and 90 hPa, τ = 10 d; implemented inside the Polvani-Kushner term | The dry model cannot grow a QBO (no convective wave source, ~1 km levels). ERA5 is observation-constrained, reaches 1 hPa in the CDS product, is already the troposphere's target and lines up with CLaMS' years. Relaxing the zonal mean only leaves the transporting waves alone. Window and τ follow WACCM's QBO nudging. Result: equatorial u RMS vs ERA5 16 → 4 m/s, amplitude 80 % of ERA5, change confined to the window (0.5 m/s outside). |
| 24 | 2026-09-04 | `XLA_PYTHON_CLIENT_MEM_FRACTION=0.92` in `scripts/env.sh` | JAX preallocates 75 % of the card by default; the compiled step holds the 29 GB one-year nudging target and at times a second copy, so the Phase 6 configuration sat just below 60 GB and the QBO term tipped it over (three OOMs). We are alone on our GPU. |
| 26 | 2026-09-09 | QBO-nudging window top raised from 4 to 1 hPa (`p_top_hpa: 1.0`, full weight 40 to 2.2 hPa); the 4 hPa chain `p8_5yr` is kept as the before-state | With the top at 4 hPa the 1-4 hPa layer became 10-15 m/s too easterly (momentum carried up out of the nudged layer, no SAO forcing above) and the model had no semiannual oscillation. At 1 hPa: equatorial u error over 1-7 hPa 22.7 -> 12.5 m/s, SAO at 2-3 hPa 5 -> 14-16 m/s (ERA5 16-21), global u RMSE 100-1 hPa vs ERA5 6.4 -> 4.9 m/s (better than Phase 6's 5.6); inside the QBO layer, vortex, age of air, tracers and throughput unchanged. The ERA5 target reaches 1 hPa, so this is the natural top. The weak westerly phases (80 % of ERA5) are unchanged: they are the 10-day relaxation, not the window (next knob). |
| 27 | 2026-09-09 | Phase 9 resolution matrix: T63 / T85 / T119 horizontally, L95 / strat63 / strat47 vertically, on the Phase 8b configuration (QBO nudging to 1 hPa); `p8b_5yr` is the T63L95 point. T127 is not constructible in JCM (valid truncations jump 106 → 119 → 170); T119 = 360 × 180 is the 1° grid | Both resolutions set the implicit diffusion of the semi-Lagrangian transport, and the age-of-air excess against CLaMS must be attributed before a grid is fixed for the aerosol work. Wave 1 is the two axes through T63L95, wave 2 the four cross points. Age of air vs CLaMS/ERA5 ranks the runs; ERA5 climatology, QBO, WACCM6 up-flux and cost stand beside it, unweighted. |
| 28 | 2026-09-09 | Vertical reductions are subsets of the L95 interfaces (`jcm_strat/levels.py`): strat63 = 8 mesosphere + the 47 L95 levels of 1.08–159 hPa intact + 8 troposphere; strat47 = 7 + 15 (1–30 hPa, every other interface) + 17 (30–159 hPa intact) + 8. Hyperdiffusion orders are mapped from the L95 lmidatm profile by the L95 index at each new level's centre; the sponge keeps L95's tau(p) (4 levels, enspodi 6.73 / 3 levels, enspodi 8). Selected by the config key `level_table: strat`; JCM's own tables are untouched | Susanne asked for L47 and L63 with the stratospheric levels intact. Subsetting keeps the stratosphere bit-identical to L95 so the vertical axis measures only the mesosphere/troposphere thinning (strat63) and the upper-stratosphere halving (strat47). ECHAM's own L47 is not that grid (~2 km throughout). Unknown level counts otherwise fall back silently to uniform del² diffusion (issue #4). |
| 29 | 2026-09-09 | The time step scales with truncation, 12 → 9 → 6 min for T63 → T85 → T119, and must divide the 5-day save interval; chained segments are 5-day multiples that never cross a calendar year (year / half / quarter = 90+90+90+95), a 366-day year runs 365 days | Phase 7 showed dt matters at fixed resolution (30 min at T63 weakens the Antarctic jet 18 %), so a fixed dt at finer grids would confound the sweep; departure-point accuracy scales with dt × ∇V. JCM truncates `save_interval/dt` and labels a tail chunk shorter than a save without integrating it, so 7 min and 91-day segments would silently lose time. Segment length follows the GPU-resident target (~30 GB): year at T63, half at T85L95, quarter at T119L95 (issue #26). |
| 30 | 2026-09-09 | The T63 terrain file is interpolated to every grid; ERA5 nudging stays 6-hourly at every resolution; the WeatherBench2 source store switches from 240×121 to 360×181 at T85 | Only T63 and T106 have native terrain bundles and the dry model has no sub-grid orography, so one file everywhere keeps the orography spectrum identical across the sweep (a limitation, recorded). A coarser nudging target would be a second changed variable. The store switch is what `jcm.data.era5.select_store` does and both stores are conservative regrids of ERA5. |
| 31 | 2026-09-10 | Phase 9 outcome: keep T63 and adopt **strat63** (`+experiment=p9_l63`) as the working grid; strat47 is the throughput option; no higher horizontal resolution for passive transport under nudging | Nine 2005–2009 chains: age-of-air RMSE vs CLaMS 0.73–0.75 yr and tropical age at 55 hPa 2.11–2.18 yr at every one of T63/T85/T119 × L95/strat63/strat47, i.e. the 0.8 yr tropical excess and the halved tropics–extratropics contrast are unchanged across a factor 3.5 in columns, 2 in stratospheric spacing and 11 in cost — the transport is converged at T63 and the bias is circulation/mixing (issues #25, #31), not implicit diffusion. strat63 reproduces L95 within 0.02 yr / 0.1 K / 0.3 m/s at 1.4 × the speed; strat47 costs 0.1 yr aloft, 1 m/s of QBO amplitude and 2–4 m/s of vortex for another 16 %. T119 improves the climatology (u RMSE 4.9 → 4.6 m/s, jets 3–6 m/s stronger, the Feb 2006 warming) at 3.5 × the cost without touching the age. |
| 32 | 2026-09-10 | (numbered 27 on the QBO branch) QBO-nudging relaxation time 1 d (`qbo.tau_days: 1.0`; was 10 d) and a mean-preserving target (`qbo.mean_preserving: true`: month-centre nodes adjusted so the linear interpolation reproduces ERA5's monthly means) | Sweep over 2005-2009 at the 1 hPa window top: tau 10 / 5 / 2 / 1 d gives 80 / 86 / 90 / 92 percent of ERA5's QBO amplitude (two springs, nudging vs the model's own easterly tendency with a ~40 d restoring time), the QBO-layer error 4.0 -> 2.3 m/s, the global u RMSE 100-1 hPa 4.9 -> 4.4, and nothing outside the window moves (age of air within 0.03 yr, tracers, jets, throughput unchanged). From 2 to 1 d the gain flattens to 2 percent: the rest is the interpolant cutting the peaks, hence the mean-preserving nodes (0.6 percent for the QBO's 28-month period, 14 percent for the 6-month SAO). 1 d keeps the model setting its own temperature (thermal-wind adjustment ~1 d) and sits in the specified-dynamics range (SD-WACCM 50 h). Cadence stays monthly: the term already interpolates to every step, and a daily target would impose sub-monthly changes that are not QBO. |
| 33 | 2026-09-11 | Phase 10 production configuration: strat63 (`+experiment=p9_l63`), QBO tau 1 d with the mean-preserving target, **6-hourly instantaneous output** (`run.save_interval 0.25`, `output_averages false`) with omega (`OmegaDiagnostic`) and every prognostic, 10-day chunks, background zlib compression of finished segments (`scripts/compact_run.py`) | The output is training data for an ML transport model whose step is 6 h: it needs instantaneous fields at that cadence and the vertical velocity, not 5-day means. A 10-day chunk keeps the frames waiting on the GPU at ~3.5 GB next to the 21 GB nudging target (30 days would be 10 GB). Compression on the GPU's critical path would double the wall time (issue #19), so it runs afterwards on the CPU: 108 → 75 GB per year. Cost: end-to-end ~30 min per simulated year, output-bound (stepping 6 ms, 4700-4800 d/hr). |
| 34 | 2026-09-11 | **Gregorian calendar** (`calendar: gregorian`, jcm_strat.main) instead of JCM's `365_day` default | Under `365_day` JCM's fraction of year is (days since 1970-01-01 mod 365)/365, which for a real start date is 5-12 days ahead of the true day of year (9 d in 2005, 12 in 2019): the Polvani-Kushner season and the QBO month ran that much early in Phases 6-9. Gregorian gives the true day of year and exactly 0 at 00:00 on 1 January, which the tracer injections rely on. Segments are true calendar years (366 in leap years) since 6-hourly saves divide any year. |
| 35 | 2026-09-11 | **Production tracer set** (`jcm_strat/advection_tracers.py`, replaces `PassiveTracers`): clocks reset below 700 hPa / below 150 hPa / at the surface; `sai`; five Gaussian **pulses injected once** at the start of the run and absorbed in the two lowest layers; four **continuous Gaussian sources** (0°/180°E/20 hPa, 30°N/60°E/100 hPa, 60°S/300°E/5 hPa, 30°S/240°E/55 hPa; A·G/90 d per step, same sink); **N2O- and CFC-11-like** tracers held at 1 below 700 hPa with WACCM's zonal-mean loss frequency and initial state. `unity` and `e90` dropped | Susanne's design for transport learning (2026-09-10/11): tracers with known initial shapes at several heights, hemispheres, longitudes and concentrations (the pulses: 'one injection at t0 and see how it gets advected'), tracers with permanent gradients that breathe with the circulation (the sources reach a steady state against the surface sink), realistic long-lived species (N2O/CFC-11 from CESM-WACCM CCMI-REFD2, the only chemistry output on this machine; ERA5 and the PARADIS CESM data have none), and the entry-age clock from #22 plus the CLaMS-style surface clock. e90 was unusable in the dry model (#23), unity's job is done by the pulses' conservation. Sites listed in the term's `DEFAULT_PULSES` / `DEFAULT_SOURCES`. |
| 36 | 2026-09-11 | N2O- and CFC-11-like tracers are **exempt from the global mass fixer** (`sl_mass_fixer_exclude: [aoa, aoa150, aoa_sfc, n2o, cfc11]`) | Same mechanism as #19: the fixer rescales the whole field by one factor per step to restore the post-physics mass, which is right for tendencies that add or remove mass (pulses, sources, sai) and wrong for a physics that imposes a *value*. With the value 1 re-imposed below 700 hPa every step, the factor (1 + ~1e-6) compounded in air sitting at 1 above 700 hPa to 1.07 within two years of the review run (`p10rev_5yr`). Without the fixer their mass error is the SL scheme's own, a few 1e-4 per year (unity, Phases 4-9). |
| 37 | 2026-09-11 | QboNudging refuses a missing ERA5 target year and uses the contiguous block of years around the requested one | `_target_now` clamps the month index at the record ends, so a missing year silently froze the target on the last available month (harmless in 2005-2009, fatal for 1990-2019). Files landing out of order from CDS must not break a run either, hence the block selection rather than a global contiguity requirement. |
| 38 | 2026-09-11 | Chains never reuse a run prefix: the 2005-2009 review run is `p10rev_*`, the 1990-2019 production chain `p10_*` | `chain_segments.sh` skips a segment whose log shows a clean exit (restartability). The production chain would have skipped 2005-2009 as done and then failed on 2010 against the review run's checkpoint with a different tracer set; caught and renamed ten minutes before it reached 2005. |
